# API Key Management - Situation Summary

## Goal
Make the API-Sports key (`VITE_API_SPORTS_KEY`) work in production/preprod browsers without committing it to the source code.

## Current State

### What Works
- Local development with `.env` file (Vite's `VITE_` prefix approach works in dev)
- Build-time validation via `envValidationPlugin` in `vite.config.ts` (fails build if key missing)

### What Doesn't Work
- The key is not available in the production browser bundle
- `import.meta.env.VITE_API_SPORTS_KEY` returns `undefined` in prod

### Root Causes Identified
1. **envDir misconfiguration** (FIXED): `vite.config.ts` had `envDir: "../"` pointing to wrong directory. Fixed to `envDir: "."`.
2. **Stencil + Vite dual-build**: The file `api-sports.constants.ts` is compiled by both Stencil and Vite. Stencil does NOT process `import.meta.env` variables.
3. **Debugging in progress**: Trying to use dynamic `import("../../../www/config.js")` but Vite can't resolve the path in dev mode.
